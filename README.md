## 📚 Изученные концепции

| Концепция | Описание |
|-----------|----------|
| **`Future<T>`** | Объект-«обещание», который вернёт значение типа `T` в будущем |
| **`async`** | Помечает функцию как асинхронную, разрешает использование `await` внутри |
| **`await`** | Приостанавливает выполнение функции до завершения `Future`, не блокируя основной поток |
| **`try/catch`** | Обработка ошибок в асинхронном коде |
| **`http.get()`** | Отправка GET-запроса, возвращает `Future<Response>` |
| **`jsonDecode()`** | Парсинг JSON-строки в `Map` или `List` |
| **`setState()`** | Уведомление Flutter об изменении состояния для перерисовки UI |
| **`Image.network()`** | Загрузка и отображение изображения по внешнему URL |
| **`CircularProgressIndicator`** | Визуальный индикатор процесса загрузки |

## ❓ Ответы на контрольные вопросы

**1. Что такое `Future<T>`? Чем отличается от обычного возвращаемого значения?**  
> `Future<T>` — это контейнер для результата, который станет доступен позже. В отличие от обычного значения, которое возвращается немедленно, `Future` представляет отложенную операцию (сеть, файл, таймер). Тип `<T>` указывает, какой тип данных вернётся после завершения.

**2. Что делает `await`? Блокирует ли он весь поток выполнения?**  
> `await` приостанавливает выполнение **текущей `async`-функции** до получения результата `Future`. При этом **основной поток (UI) не блокируется** — приложение остаётся отзывчивым, пользователь видит индикатор загрузки и может взаимодействовать с интерфейсом.

**3. Зачем `setState()` вызывается дважды в `_fetchPhoto()`?**  
> - **Первый вызов:** устанавливает `_isLoading = true` → показывает `CircularProgressIndicator`  
> - **Второй вызов:** устанавливает `_isLoading = false` и сохраняет результат (`_imageUrl` или `_errorMessage`) → отображает картинку или ошибку  
> Без `setState()` Flutter не узнает об изменении данных и не обновит интерфейс.

**4. Почему кнопке передаётся `_fetchPhoto` без скобок, а не `_fetchPhoto()`?**  
> - `onPressed: _fetchPhoto` — передаём **ссылку на функцию**, которая выполнится при нажатии  
> - `onPressed: _fetchPhoto()` — **немедленно вызовем функцию** при построении виджета (ошибка логики)  
> Это стандартный паттерн для обработчиков событий во Flutter.

**5. Чем `Image.network()` отличается от `Image.asset()`?**  
> | Метод | Источник | Когда использовать |
> |-------|----------|------------------|
> | `Image.network(url)` | Внешний сервер по HTTP | Динамический контент (фото из API) |
> | `Image.asset('path')` | Локальная папка `assets/` | Статичные ресурсы, встроенные в приложение |
> 
> Для `Image.asset()` необходимо заранее указать файлы в `pubspec.yaml` в разделе `flutter.assets`.
